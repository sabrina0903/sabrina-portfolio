# Sabrina Wong - Portfolio

Personal portfolio built with React and Vite, highlighting website development, client projects, academic work, and experience in information systems.

Featured projects include Control Theory Calisthenics, a client website for Hunter Stein, and Ang Mo Racing, an independently built apparel storefront. The site also includes professional experience, technical skills, contact links, and a downloadable resume.

## Run locally

Install dependencies and start the development server:

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Vite writes the static website to `dist/`. Build output, dependencies, and local tooling are excluded from version control.

## Main files

- `src/App.jsx`: portfolio content and interactions
- `src/App.css`: layout and component styling
- `src/index.css`: global styling and accessibility
- `public/sabrina-wong-resume.pdf`: downloadable resume

External project links lead to their respective live websites and repositories.
